### Learnings for future iterations
- **CSS-only dropdowns**: Use Tailwind's `group` and `group-hover:` for desktop hover dropdowns without JavaScript
- **Mobile menu pattern**: Add `hidden` class and toggle with JavaScript; use `classList.toggle('hidden')`
- **Dropdown positioning**: `absolute left-0 mt-2` positions dropdown below the trigger; `z-50` ensures it appears above content
- **Transition effects**: `opacity-0 invisible` → `group-hover:opacity-100 group-hover:visible` with `transition-all duration-200` for smooth appearance
- **Category headers**: Use `text-xs font-semibold text-gray-500 uppercase tracking-wider` for small, muted category labels
- **Touch targets**: Mobile menu items use `px-3 py-2` for sufficient tap targets (approximately 44px height)
- **Navigation consistency**: The src/pages/index.html file is a legacy file with different styling - left unchanged as it uses a completely different template
- **This also satisfies US-014**: Mobile hamburger menu with expandable categories was implemented as part of this story
